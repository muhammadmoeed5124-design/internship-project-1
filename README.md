# 🚗 Khattak Motors

A modern, responsive car dealership website built with **HTML, CSS, and Vanilla JavaScript**.

Khattak Motors is a fictional premium car dealership based in **Peshawar, Pakistan**, featuring a vehicle inventory, filtering system, responsive navigation, workshop information, and contact sections.

## ✨ Features

- 🚘 Modern car dealership landing page
- 📱 Fully responsive design
- 🔎 Filter vehicles by:
  - Body type
  - Car make
  - Price range
- 🏎️ Featured vehicle inventory
- 📋 Vehicle specifications
- 📱 Mobile navigation menu
- ✨ Scroll reveal animations
- 📌 Sticky navigation header
- 🔄 Reset inventory filters
- 📞 Test-drive call-to-action
- 🛠️ Workshop information
- 📧 Contact information
- 🎨 Premium dark automotive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash Images
